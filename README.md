# MD Fahim — Futuristic Creative Portfolio

Responsive static portfolio built with HTML, CSS and JavaScript.

## Portfolio sections
- **Behance Projects:** 29 public project cards linked to their Behance case studies.
- **YouTube Projects:** a separate video portfolio section, ready for the user's YouTube project links and thumbnails.

## Publish with GitHub Pages
1. Create a public repository named `md-fahim-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

Behance thumbnails load from Behance's public CDN and need an internet connection. The YouTube section is currently a placeholder until video links and project thumbnails are provided.
